This project was completed using an Arduino Uno r3, which runs on the ATmega328P microcontroller.

The goal of this project was to complete a maze using bumpers (contact switchs) that registered when the car hit an object
and use IR line sensors to follow a line through a track. I have included both codes in this repository.

This was completed using C++ and the Arduino IDE.

Our group implemented extra functions for the line follower, such as an odometer and the ability to reverse at the end of the track.
